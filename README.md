# password-generator-javafx
🔐 Secure Password Generator built with Java 21 &amp; JavaFX. Features single-use clipboard protection, secure random generation, and local file persistence.


> ⚠️ **Note importante :** Le code le plus récent et à jour se trouve sur la branche **`master`**. 
> Pour récupérer le projet, veuillez basculer sur la branche `master` :
> ```bash
> git checkout master
> git pull origin master
> ```
